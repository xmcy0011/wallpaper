# 壁纸应用

## 提示词

应用壁纸逻辑设计：

- 在详情页（wallpaper_detail_page.dart）点击 "应用壁纸" 按钮后
  - 调用系统设置服务（system_settings_service.dart）中的 getWallpaperPath() 函数，获取壁纸保存路径
    - 下载壁纸
      - 调用 storage.dart 中的 saveWallpaperFromURL() 函数下载保存壁纸
        - 分辨率：默认4K（3840x2160）
      - 下载进度显示
        - 下载进度显示在详情页（wallpaper_detail_page.dart）中的 "应用壁纸" 按钮上，文字显示 "%+进度值"，背景效果添加进度条变色
        - 当下载进度达到 100% 时，按钮文字变成 "已应用"
    - 应用壁纸
      - 根据 player.dart 中的 play() 函数播放壁纸
