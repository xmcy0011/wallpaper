# 实现资源区并添加切换效果

## 提示词

增加资源区页面，当点击 home.dart 中的 _buildTopBar() 的 ”资源区“时，切换显示。界面请参考图片。

![资源区参考图片](images/03-资源区参考图片.png)

资源区页面已就绪，点击 _buildTopBar 的「资源区」Tab 会切换显示。主要改动如下：

## 1. 新增 `resource_zone_page.dart`

参考参考图实现布局，包含：

- **主分类导航**：视频壁纸、图片壁纸（默认选中）、互动壁纸、鼠标、图标、任务栏、开始菜单、美化套餐；右侧有「专题活动」「人气作者」
- **一级筛选**：全部、动漫、游戏、美景、文字、可爱、趣味、简约、科幻等
- **二级筛选**：美女、帅哥、AI视频
- **排序与筛选**：默认排序下拉、带鱼屏、4K超清 按钮
- **壁纸网格**：4 列网格，支持 SVIP 标识
- **分页**：页码、跳转输入框

## 2. 修改 `home.dart`

- 使用 `TabBarView` 包裹主内容，Tab 与 TabBar 对应：
  - **推荐**：原有轮播、推荐栏、热门壁纸
  - **资源区**：资源区页面
  - **SVIP**：占位提示
  - **组件**：占位提示

## 3. 行为说明

点击 TabBar 的「资源区」时，`TabController` 会切换 TabBarView，对应显示资源区内容。
