# 实现自定义标题栏

## 提示词

```text
最小化、最大化和关闭以及标题栏，请帮我实现成自定义的，以使界面更美观。样式可以参考上图。
```

自定义标题栏已实现，主要改动如下：

## 实现总结

### 1. 添加依赖

在 `pubspec.yaml` 中加入 `window_manager: ^0.5.1`，用于无边框窗口和窗口控制。

### 2. 窗口初始化 (`lib/main.dart`)

- 桌面平台（Windows / macOS / Linux）下隐藏系统标题栏
- 使用 `TitleBarStyle.hidden` 隐藏原生标题栏

### 3. 自定义标题栏组件 (`lib/widgets/custom_title_bar.dart`)

参考 upupoo 风格，实现内容包括：

- **布局**：白色背景，扁平化设计
- **左侧**：蓝色 Logo + 粗体标题「壁纸APP」+ 灰色副标题「收藏」
- **右侧**：
  - 功能图标：手机 APP、耳机、扩展、分割线、刷新
  - 窗口控制：最小化、最大化/恢复、关闭
- **交互**：
  - 左侧区域可拖拽移动窗口
  - 双击标题栏可最大化/恢复
  - 关闭按钮悬停时为红色
  - 其他按钮悬停时有灰色背景

### 4. 平台兼容 (`lib/utils/`)

- 使用条件导入，保证在 Web 下也能正常编译
- 仅在桌面平台显示自定义标题栏

### 5. 集成到首页 (`lib/views/home.dart`)

在原有深色导航栏上方增加自定义标题栏。
